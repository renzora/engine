# Light Streaks

Anamorphic streaks off bright highlights: the horizontal flare an anamorphic lens throws. `threshold` picks what counts as bright, `direction` sets the streak angle.

**Use it:** add a **Post Process** component to the camera or the World Environment, then drag `light_streaks.wesl` from the Assets panel onto it.

**Settings:** Intensity, Threshold, Samples, Direction
