# Scanlines

CRT scanlines: horizontal dark lines across the frame, optionally drifting.

For the full CRT treatment (curvature, colour fringe and vignette sharing one curved UV), use **CRT** instead of stacking this with the others.

**Use it:** add a **Post Process** component to the camera or the World Environment, then drag `scanlines.wesl` from the Assets panel onto it.

**Settings:** Intensity, Count, Speed
